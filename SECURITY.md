# Security Policy

Welcome! This policy is for reporting security issues about Titanium, whether it's for the bot, website, or dashboard. It tells you what should be reported, and how  security issues should be reported. 

## What not to report

If you believe you have discovered a true security issue (sending unwanted messages without permission, reading / writing config of other servers you don't have access to, getting private information of other sevrers / users, etc) then you are in the right place. 

If you have discovered a bug that does not cause a security issue (dashboard page not working, bot feature broken, etc) please report this via the Issues tab on Titanium's GitHub repository, or in the [Discord server](https://titanium.fyi/server) if you do not wish to use GitHub.

## Supported Versions

### Bot

Only the latest commit of Titanium v2 is supported. Older commits of Titanium v2 are not supported, as I am constantly applying fixes and new features / improvements. Titanium v1 is not supported, and issues / security reports for Titanium v1 will be rejected. 

### Dashboard and Website

The latest commit of the Titanium Website or Dashboard are supported. Older commits are not supported.

## Reporting a Vulnerability

If you believe you have discovered a security issue in Titanium, whether it's in the bot itself, the dashboard, or the website, please report it to me. Once I have acknowledged your report and fixed the issue, you will receive full credit if you wish. Please use one of the following two methods to report security issues:

1. **GitHub Security Reporting** - You can privately report an issue to me using the report feature in the security tab of Titanium's GitHub repo.

2. **Ticket in Discord Server** - If you would not like to use GitHub to report the security issue, you can use the ticket system in Titanium's [Discord server.](https://titanium.fyi/server)

> [!IMPORTANT]
> Please do not discuss or demonstrate security issues publicly before they are fixed. Once I have fixed the issue, I will discuss disclosure of the issue with you.

## Bug Bounty

I cannot guarantee that a bug bounty will be issued (or if one is issued, what it will be) as I do not make any money / income from Titanium.
